Install in Chrome

  1. Download the Chrome ZIP file and extract it.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked.
  5. Select the extracted x-media-grid-restore folder.
  6. Reload an X profile’s Media page.

Install in Firefox

  1. Download the signed Firefox .xpi file.
  2. Open about:addons in Firefox.
  3. Click the gear icon.
  4. Select Install Add-on From File.
  5. Choose the downloaded XPI file and click Add.
  6. Reload an X profile’s Media page.
